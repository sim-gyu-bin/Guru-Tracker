description: 동기화 진입점·DB lease·스냅샷 회전·outbox를 구현하거나 검토할 때 사용한다.
---

`.omp/RULES.md`의 동기화 불변 조건을 아래 구현 경계에 적용한다. 단순 원문 조사나 파서 수정에는 이 실행 절차를 강제하지 않는다.

1. Supabase Cron에서 보호된 Next.js 내부 엔드포인트까지 호출 계약과 서버 전용 비밀값 경계를 확인한다.
2. 스케줄 호출과 사용자 접근 경로는 같은 멱등 동기화 조정자와 DB lease를 사용한다. lease를 얻지 못한 호출은 중복 수집·회전을 하지 않는다.
3. 사용자 접근에서는 캐시를 먼저 반환한다. 캐시가 오래됐거나 스케줄 작업이 뒤처진 경우에만 같은 조정자를 요청하며, 초기 화면을 수집 완료까지 막지 않는다.
4. 조정자는 공식 원문 검증과 실제 변경 판정을 마친 뒤에만 현재/직전 두 스냅샷을 원자적으로 회전하고 dataset version을 증가시킨다. 실제 변경 이벤트에는 event/document 고유 키를 부여한다.
5. 커밋된 변경 이벤트만 알림 outbox에서 처리한다. outbox는 event/document 고유 키로 멱등하게 기록하고, 전송 실패가 원본 데이터 transaction을 되돌리지 않게 한다. 전달 완료 outbox와 이벤트 이력의 짧은 보존 기간·정리 경로를 설계하며 정확한 기간은 운영 결정으로 남길 수 있다. 실제 정리 실행은 전역 삭제 승인 정책을 따른다.
