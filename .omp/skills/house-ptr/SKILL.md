description: 미국 하원 공식 PTR을 검증하고 스냅샷화하는 절차
---

이 스킬은 Nancy Pelosi의 미국 하원 공식 Periodic Transaction Report(PTR)에만 적용한다.

1. 공식 하원 PTR 원문과 문서 식별자를 확인한다.
2. 제출자, 보고·거래 시점, 자산, 거래 유형, 금액 범위를 원문에서 검증한다.
3. 이전 현재 스냅샷과 비교해 실제 문서 또는 정규화 결과가 바뀌었는지 판정한다.
4. 검증이 끝난 새 PTR만 현재와 직전 두 스냅샷으로 원자적으로 교체한다. 실제 변화가 없으면 dataset version을 올리지 않는다.
5. 매시간 Supabase Cron 호출과 오래된 캐시·뒤처진 스케줄에서의 사용자 접근 대체 호출은 같은 멱등 동기화 조정자와 DB lease를 통해 실행한다. 사용자에게는 캐시를 먼저 제공한다.

금액 범위나 공개 형식의 한계를 정확히 표시하고, 제3자 추적 사이트의 요약을 사실 근거로 사용하지 않는다. 결과에는 공식 URL, 문서 식별자, 확인 필드, 변경 여부, 보류 이유를 남긴다.
