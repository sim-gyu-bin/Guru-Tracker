---
name: llm-wiki
description: LLM Wiki의 원본 증거와 합성 지식을 분리해 기록하는 절차
---

Wiki를 다룰 때 먼저 `.wiki/raw`와 `.wiki/wiki`의 소유권을 구분한다.

- `.wiki/raw`는 사람이 소유하는 불변 증거 원본이다. LLM은 수정, 요약으로 덮어쓰기, 런타임 공시 파일 저장을 하지 않는다.
- `.wiki/wiki`는 LLM 소유 합성 지식이다. 초기 생성 지식 페이지는 영어로 작성한다.
- 런타임 공시 파일은 Supabase Storage에 보관하며 `.wiki/raw`에는 대표 개발 샘플이 필요할 때만 사람이 추가한다.

합성 페이지에는 원문 출처, 관찰 사실, 해석, 불확실성 또는 보류 사항을 분리한다. 원문에 없는 수치나 결론을 보강하지 않으며, SEC 13F를 실시간 보유로 표현하거나 Burry 옵션의 정확한 손익을 추론하지 않는다. 대화에서 나온 확정 결정은 구조화해 index와 log에 반영하되, 미결 사항은 확정으로 승격하지 않는다.
