---

커밋은 요청받은 경우에만 만든다. 제목은 반드시 다음 형식을 따른다.

```text
이모티콘 타입: 제목
```

제목에는 타입 앞 이모티콘을 반드시 포함한다. 제목은 기본적으로 한국어로 작성하고 50자 이내로 유지하며, 변경사항이 한눈에 드러나게 쓰고 끝에 마침표를 붙이지 않는다.

사용 가능한 타입은 다음과 같다.

- `✨ feat`: 새로운 기능 추가
- `🛠 fix`: 버그 수정
- `🚑 hotfix`: 긴급 수정
- `📝 docs`: 문서 수정
- `⚡️ perf`: 성능 개선
- `🌐 localization`: 다국어 처리
- `🚩 lint`: 린트룰 추가 및 수정
- `💎 style`: 로직 변경 없는 스타일 수정
- `♻️ refactor`: 코드 리팩터링
- `✅ test`: 테스트 코드 추가 및 수정
- `📦️ chore`: 빌드, 설정, 패키지 매니저, 기타 작업

본문은 제목 아래 한 줄을 띄운 뒤 기본적으로 한국어로 구체적인 변경 내용을 쓴다. 여러 줄이면 각 줄을 `-`로 시작하고 각 줄 길이는 72자 이내를 권장한다. `git commit -m`으로 본문을 넣을 때 `\n` 문자열을 직접 쓰지 않는다. 본문 개행에는 실제 줄바꿈이나 ANSI-C quoting(`$'...'`)을 사용한다.

이슈 번호나 후속 추적 정보가 있으면 footer에 작성하며 `Close #7` 형식을 따른다. 관련 내용이 없으면 footer는 생략할 수 있다. footer는 본문 뒤 한 줄을 띄워 작성한다.
