---
name: web-push
description: PWA에서 표준 Web Push와 VAPID를 안전하게 구독·전송하는 절차
---

이 스킬은 Guru Tracker의 변경 알림에만 적용한다. Firebase나 네이티브 푸시를 도입하지 않는다.

1. 서비스 워커와 VAPID를 사용하는 표준 Web Push로 구현한다. VAPID 개인 키와 구독 처리 비밀값은 서버 전용으로 관리하며 클라이언트·저장소·로그에 기록하지 않는다.
2. 알림 권한 요청과 구독은 사용자의 명시적 제스처에서만 시작한다. 첫 화면 로드에서 권한을 강요하지 않고, 구독·해제 상태와 실패를 사용자에게 정확히 보여 준다.
3. iOS에서는 일반적인 Web Push 흐름을 위해 사용자가 PWA를 홈 화면에 설치해야 함을 안내한다. 이를 위해 Apple Developer 계정은 필요하지 않다.
4. 검증된 DB transaction이 실제 변경 이벤트를 커밋한 뒤에만 event/document 고유 키의 outbox 항목을 전송한다. 같은 이벤트·문서는 한 번만 알리며, 전송 실패가 원본 데이터 변경을 롤백하지 않게 한다.
5. Web Push 응답이 404 또는 410이면 만료된 구독을 삭제한다. 전달된 outbox와 이벤트 이력은 짧고 명시된 보존 기간 후 정리해 저장 공간을 제한한다.
