# 프로젝트 불변 조건

## 브랜치 작업

- 모든 작업은 `develop` 브랜치에서 수행한다. `main` 병합·푸시를 마치면 반드시 `develop`으로 돌아온다.

## 공식 출처

- Stanley Druckenmiller, Michael Burry, Philippe Laffont, Brad Gerstner, David Tepper는 공식 SEC 13F만 사용한다. 13F를 실시간 데이터로 표현하지 않으며 Burry 옵션의 정확한 손익을 추론하거나 단정하지 않는다.
- Cathie Wood는 ARK 공식 holdings/trades만 사용한다. 접근 공백 중 누락된 일별 ARK 이력은 접속 시 재구성할 수 없다.
- Nancy Pelosi는 미국 하원 공식 PTR만 사용한다.

## 동기화와 전달

- Supabase Cron(`pg_cron` + `pg_net`)만 보호된 Next.js 내부 엔드포인트를 매시간 호출한다. 비밀값은 Supabase Vault와 서버 전용 설정에 둔다. Vercel Hobby Cron은 사용하지 않으며 Supabase Edge Function은 구현 근거 없이 요구하지 않는다.
- 스케줄과 접근 대체 경로는 하나의 멱등 조정자와 DB lease를 공유한다. 화면은 캐시를 먼저 보여 주고 캐시가 오래됐거나 스케줄 작업이 뒤처졌을 때만 조정자를 호출한다.
- 검증된 새 출처와 실제 변경이 있을 때만 하나의 DB transaction에서 현재/직전 두 스냅샷 원자 회전·dataset version·변경 이벤트를 기록한다. 커밋된 이벤트만 event/document 고유 키 outbox로 전송하고 중복을 막는다. 푸시 실패는 원본 데이터를 롤백하지 않으며 전달 outbox·이벤트 이력은 짧은 보존 기간으로 정리하도록 설계한다. 실제 데이터 정리 실행은 전역 삭제 승인 정책을 따른다.
- Web Push는 서비스 워커와 VAPID를 쓰고 사용자 제스처로만 opt-in한다. iOS 일반 흐름에는 홈 화면 PWA 설치가 필요하며 Apple Developer 계정·Firebase·네이티브 푸시는 요구하지 않는다.

## UI 디자인

- UI 설계·구현·검토에는 공식 upstream의 프로젝트 로컬 설치본인 `ui-ux-pro-max` 스킬을 활용한다. 아래 UI 제약은 upstream 스킬이 아닌 프로젝트 규칙이다. 특정 제품이나 브랜드를 고정 시각 기준으로 삼지 않으며, 서비스 목적·정보 우선순위·한국어 가독성에 맞게 디자인 후보를 평가한다. 외부 로고·브랜드 자산을 복제하지 않는다.
- 색상·밀도·간격·타이포그래피·차트는 공시 조회 목적에 맞게 선택한다. 검색 결과를 그대로 적용하지 않고 탐색·목록·상세의 정보 위계와 사용성을 검증하며, 불필요한 장식·애니메이션은 도입하지 않는다.
- 데스크톱은 명확한 탐색 영역과 밀도 있는 목록·상세 구성을 사용하되, 모바일 PWA에서는 단일 열 중심으로 재배치한다. 데스크톱 화면을 그대로 축소하지 않으며 한국어 가독성, 터치 영역, 키보드 포커스와 색 대비를 확보한다.
- 라이트·다크 등 테마 방향은 작업 범위와 사용자 요구에 맞게 정한다. 색상·간격·모서리·텍스트 스타일은 공통 디자인 토큰과 기존 컴포넌트를 재사용하고, 화면마다 별도 스타일 체계를 만들지 않는다.
- UI는 Tailwind CSS 유틸리티와 shadcn/ui 컴포넌트로 구현한다. 레이아웃·간격·반응형·상태 스타일은 JSX의 Tailwind 클래스로 작성하고, 버튼·배지·표 등은 필요한 shadcn/ui 컴포넌트를 추가해 재사용한다.
- `globals.css`에는 Tailwind 로딩, 공통 테마 토큰과 최소한의 기본 스타일만 둔다. 화면·컴포넌트별 CSS 클래스, 전역 선택자, `@apply`로 포장한 별도 스타일 체계는 만들지 않는다. 기존 화면별 CSS는 호출부를 Tailwind·shadcn/ui로 전환한 뒤 제거한다.
- 로딩·빈 데이터·오류·갱신 상태도 같은 시각 체계를 따른다. 장식보다 공시 기준일·제출일·원문 근거와 데이터 상태의 식별을 우선하며, UI 변경은 실제 데스크톱·모바일 화면에서 확인한다.
- 모든 같은 탭 페이지 이동은 루트의 공통 상단 프로그래스를 즉시 표시하고 이동 완료·실패·취소에 맞춰 종료한다. 내부 링크는 `GuruLink`, 프로그램 이동은 `useGuruRouter`를 사용하며 모바일 메뉴가 닫히거나 링크가 사라져도 진행 상태를 유지한다. 브라우저 뒤로·앞으로 이동과 로그인·로그아웃 문서 전환도 포함한다. 새 탭·다운로드·동일 URL·페이지 내 해시 이동은 제외하며, 외부 인증 페이지로 넘어간 뒤에는 해당 문서가 표시를 소유한다. 새 이동 경로를 추가할 때 모바일·데스크톱에서 느린 이동, 빠른 이동, 완료 후 표시 해제를 확인한다.

## 코드 주석

- 외부로 노출되는 함수·타입·컴포넌트·훅과 수집 파서, 동기화·스냅샷 회전, DB transaction의 핵심 코드는 한글 주석으로 목적, 입력·출력, 불변 조건과 실패 조건을 설명한다.
- 출처 제약·단위·기준일과 제출일·시간대·식별자 선택·브라우저 및 플랫폼 우회처럼 코드만으로 알 수 없는 외부 의미를 해당 코드 가까이에 기록한다.
- 비자명한 분기·예외는 처리 이유를 설명한다. 자명한 코드를 줄마다 번역하지 않는다. 변경 시 관련 주석을 갱신하고 구현과 모순되는 주석을 남기지 않는다.
