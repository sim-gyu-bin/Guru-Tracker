# 코드 주석 정책

> 이것은 **대화 내용을 그대로 옮긴 것이 아닌 구조화 메모**다. Guru Tracker 코드 작성 시 적용할 주석 규칙을 기록한다.

## 사용자 결정

- 코드 작업에서는 필요한 주석을 철저히 작성한다.
- 프로젝트의 개발 지침과 지속 규칙으로 적용한다.

## 적용 해석

- 외부로 노출되는 API와 핵심 도메인 로직에는 목적, 입력·출력, 불변 조건과 실패 조건을 한글 주석으로 설명한다.
- SEC 13F, ARK, PTR의 출처 제약과 단위·날짜·시간대·식별자 선택처럼 코드만으로 알 수 없는 이유를 코드 가까이에 기록한다.
- 비자명한 분기와 예외 처리에는 무엇을 하는지 반복하기보다 왜 필요한지 설명한다.
- 자명한 코드를 줄마다 번역하는 주석은 피하고, 코드 변경 시 관련 주석을 함께 갱신한다.
